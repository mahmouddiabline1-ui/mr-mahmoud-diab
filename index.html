From Human Information to Digital Data
من المعلومات البشرية إلى البيانات الرقمية

Definition: Information is anything meaningful that humans communicate or store — words, pictures, or sounds. Computers convert this information into digital data so it can be stored and processed.

التعريف: المعلومات هي أي شيء له معنى بالنسبة للإنسان مثل الكلمات والصور والأصوات. الكمبيوتر يحول هذه المعلومات إلى بيانات رقمية حتى يستطيع تخزينها ومعالجتها.

Explanation & Examples — الشرح والأمثلة
Explanation — شرح مبسط

Computers do not see words, pictures, and sounds the same way humans do. They first convert them into digital data that can be stored, processed, and transmitted.

الكمبيوتر لا يرى الكلمات والصور والأصوات كما نراها نحن. في البداية يحوّلها إلى بيانات رقمية يستطيع تخزينها ومعالجتها ونقلها.

Examples / أمثلة
  • Text → letters and wordsالنص ← حروف وكلمات، مثل رسالة WhatsApp.
  • Image → pixelsالصورة ← Pixels، مثل صورة الكاميرا على الموبايل.
  • Sound → digital samplesالصوت ← عينات رقمية، مثل تسجيل Voice Note.

Bit & Binary
البِت والنظام الثنائي

Definition: A Bit is the smallest unit of data in a computer. It has only two states: 0 or 1. Binary is the number system that uses only 0 and 1.

التعريف: البِت هو أصغر وحدة بيانات في الكمبيوتر وله حالتان فقط: 0 أو 1. والنظام الثنائي هو النظام الذي يستخدم الصفر والواحد فقط.

Explanation & Examples — الشرح والأمثلة
Explanation — شرح مبسط

Binary is the simplest way to represent states inside a computer. Think of it as two choices only: off/on, no/yes, 0/1. The goal here is understanding the idea, not doing conversions.

النظام الثنائي هو أبسط طريقة لتمثيل الحالات داخل الكمبيوتر. تخيّله كاختيارين فقط: إيقاف/تشغيل، لا/نعم، 0/1. المطلوب فهم الفكرة وليس حل تحويلات.

Examples / أمثلة
  • Light switch: OFF = 0 / ON = 1مثال يومي: مفتاح النور؛ مطفأ = 0 ومضاء = 1.
  • One bit stores one binary state.كل Bit يخزن حالة ثنائية واحدة.
  • Focus on the concept — no manual binary conversion.المطلوب فهم الفكرة فقط، من غير مسائل تحويل.

Character Encoding
ترميز الأحرف

Definition: Character Encoding is a method that assigns a numerical representation to each character so computers can store and exchange text correctly.

التعريف: ترميز الأحرف هو طريقة تعطي كل حرف تمثيلًا رقميًا متفقًا عليه حتى تستطيع الأجهزة تخزين النصوص وتبادلها بصورة صحيحة.

Explanation & Examples — الشرح والأمثلة
Explanation — شرح مبسط

Character encoding gives every character a numerical representation. This is how a computer can store a letter, send it to another device, and display the same character again.

ترميز الأحرف يعطي كل حرف تمثيلًا رقميًا. بهذه الطريقة يستطيع الكمبيوتر تخزين الحرف وإرساله لجهاز آخر ثم عرضه مرة أخرى بنفس الشكل.

Examples / أمثلة
  • A → 65 → 01000001الحرف A له رقم متفق عليه، ثم يُمثَّل رقميًا داخل الكمبيوتر.
  • The same character should appear correctly on different devices.مثال يومي: تبعت رسالة من Android وتفتحها على iPhone فتظهر نفس الحروف.
  • Encoding represents characters; it does not understand their meaning.الترميز يحدد كيف نخزن الحرف، وليس معنى الكلمة.

ASCII & Unicode
ASCII و Unicode

التعريف: ASCII معيار ترميز محدود نسبيًا يغطي أساسًا الإنجليزية والأرقام والرموز، بينما Unicode صُمم لتمثيل حروف لغات كثيرة ومنها العربية.

Explanation & Examples — الشرح والأمثلة
Explanation — شرح مبسط

ASCII and Unicode are standards for representing characters. ASCII is limited, while Unicode supports many languages and symbols, including Arabic.

ASCII وUnicode معايير لتمثيل الأحرف. ASCII محدود نسبيًا، بينما Unicode يدعم لغات ورموزًا كثيرة ومنها العربية.

  • One common standard lets devices exchange many languages correctly.مثال: ملف فيه عربي وإنجليزي وإيموجي يظهر بصورة صحيحة على أجهزة مختلفة.

Hexadecimal
النظام السداسي عشر

Definition: Hexadecimal is a base-16 number system that uses 0–9 and A–F. It is often used as a shorter human-friendly representation of long binary values.

التعريف: النظام السداسي عشر نظام عد أساسه 16 ويستخدم الأرقام 0–9 والحروف A–F، ويظهر كثيرًا كتمثيل أقصر وأسهل للبشر من السلاسل الثنائية الطويلة.

Explanation & Examples — الشرح والأمثلة
Explanation — شرح مبسط

Hexadecimal is mainly useful because it shortens long binary values into a form that is easier for humans to read. At this stage, focus on where you see it, not on manual conversion.

النظام السداسي عشر مفيد لأنه يختصر القيم الثنائية الطويلة إلى شكل أسهل للبشر في القراءة. في هذه المرحلة ركّز على أين نراه، وليس على التحويل اليدوي.

Examples / أمثلة

Algorithm

التعريف: الخوارزمية هي مجموعة خطوات واضحة ومرتبة تُستخدم لحل مشكلة أو تنفيذ مهمة.

Explanation & Examples — الشرح والأمثلة
Explanation — شرح مبسط

An algorithm is simply a clear plan. Before writing code, we decide the steps needed to reach a result. If the steps are unclear, the program will also be unclear.

الخوارزمية ببساطة هي خطة واضحة. قبل أن نكتب كود نحدد الخطوات اللازمة للوصول للنتيجة. إذا كانت الخطوات غير واضحة، فالبرنامج نفسه سيكون غير واضح.

Network Security & Firewall
أمان الشبكات والجدار الناري

Network Security: Protecting devices and data inside a network. Firewall: filters network traffic using rules.

أمان الشبكات: حماية الأجهزة والبيانات داخل الشبكة. Firewall: بيفلتر حركة الشبكة حسب قواعد ويقرر مين يعدّي ومين يتمنع.

Explanation & Examples — الشرح والأمثلة
Explanation — شرح مبسط

Network security protects devices and data while they communicate. A firewall is one simple example: it checks traffic against rules and decides what should be allowed or blocked.

أمان الشبكات يحمي الأجهزة والبيانات أثناء التواصل. والـFirewall مثال بسيط: يفحص حركة الشبكة حسب قواعد ويقرر ما الذي يُسمح له بالمرور وما الذي يتم منعه.

Everyday Example / مثال يومي
  • A firewall is like a security guard at a school gate.الـFirewall زي حارس على باب المدرسة: المسموح يعدّي والمشبوه يتمنع.
