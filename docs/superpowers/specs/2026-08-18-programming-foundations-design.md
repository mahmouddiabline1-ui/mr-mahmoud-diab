# Programming Foundations Insert

## Goal

Insert a short bilingual programming-foundations sequence immediately after the existing **Programming Language** slide and before the current `print()` slide. It should make the path from a programming idea to running code clear for second-secondary students.

## Slide order

1. **Programming vs Programming Language** — distinguish solving/planning a task from the language used to write executable instructions; include Python, Java, JavaScript, and C++ examples.
2. **High-Level vs Low-Level Languages** — compare human-readable languages with languages closer to the machine; use Python/Java/JavaScript and Assembly/Machine Language examples.
3. **Why not write 0 and 1?** — explain readability, writing difficulty, and error risk, then connect that problem to programming languages.
4. **Where do we write code?** — introduce text editors and code editors, without implying Word is a recommended coding tool.
5. **IDE** — define Integrated Development Environment as an all-in-one place to write, run, and find errors; give VS Code and PyCharm as examples.
6. **How the computer understands code** — visualize: code → compiler/interpreter → machine language → execution → result.
7. **Syntax** — define code-writing rules using one correct and one incorrect Python example, with a small interaction to reveal the mistake.

## Presentation design

Each slide uses the existing dark bilingual style: concise Arabic definition, English term, student-friendly everyday analogy/example, and an animated CSS figure or mini interaction. Arabic flow arrows use RTL visual order. No source links are shown.

## Compatibility and verification

The slides retain existing `slide` behavior, scroll snapping, mobile layout, and the fixed site badge. Existing slides (`print()`, text/numbers, variables, input/output, data types, conditions, loops, debugging) remain unchanged and follow the inserted sequence. Verification will include HTML structural checks, a local visual pass, Git commit/push, and GitHub Pages deployment confirmation.
